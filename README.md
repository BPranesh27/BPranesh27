## 🚀 Featured Projects

### 1. 🤖 DeedCraft AI — Automated Legal Deed Generation

**Tech Stack:** Python · Open-Source LLMs · Semantic RAG

An AI-powered legal document intelligence system designed to automate the analysis of historical parent deeds and Encumbrance Certificates for property document verification and deed generation.

**Key Features**
- 📄 Automates the extraction and analysis of information from historical property documents.
- 🔍 Uses semantic Retrieval-Augmented Generation (RAG) and clause-aware document chunking to retrieve relevant legal information.
- 🧠 Uses a legal knowledge graph to map ownership history and encumbrances.
- ⚡ Targets faster deed generation and reduced manual document review.

**Reported project results:** Approximately 8 hours reduced to under 3 minutes for deed generation, with 98.2% extraction accuracy across 5+ records.

### 2. 🏠 SpareHub — Peer-to-Peer Item Rental Platform

**Tech Stack:** React.js · Spring Boot · Java · Python · FastAPI · MySQL · JWT · REST APIs

A full-stack platform that enables users to list, discover, book, and rent items from other users.

**Key Features**
- 📦 Item listing, discovery, and rental management.
- 🔐 JWT authentication and role-based access control.
- 🔄 REST APIs for item management, availability validation, bookings, cancellations, and rental status tracking.
- 🤖 Python/FastAPI AI service integrated with Spring Boot for personalized item recommendations based on user preferences and rental activity.
- 🗄️ MySQL database integration for application data.
